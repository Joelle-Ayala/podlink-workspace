# Founder Inputs Needed

Claude Code can do much of the technical work, but it needs these inputs or approvals.

## Required files/access

- MagicAI folder or zip
- Biolink folder or zip
- CodeCanyon install docs/licenses
- GitHub repo access
- Railway access/MCP if available
- database access locally or on Railway
- Cloudflare/GoDaddy DNS access or approval path
- Stripe test keys
- email provider credentials
- OpenAI/AI provider keys

## Product decisions

- launch tier names and pricing
- free limits
- AI/video usage limits
- whether Creator tier is public at launch
- whether social publishing is enabled at launch
- whether analytics is shown as coming soon or hidden

## Brand decisions

- Podlink logo/wordmark or permission to use text logo temporarily
- color palette or permission to use existing theme with Podlink name
- support email
- company/legal name for terms/privacy

## Final approvals

- copy accuracy
- pricing
- legal pages
- payment flow
- public launch readiness
