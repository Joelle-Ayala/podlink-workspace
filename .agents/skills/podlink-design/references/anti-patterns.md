# Anti-patterns and subtraction

This file exists because agents tend to add visible treatment until a page “looks designed.” Podlink should usually move in the opposite direction.

## Refuse list

Do not default to:

- purple/blue AI gradients,
- gradient text as a generic emphasis device,
- glowing AI orbs,
- decorative sparkles,
- glassmorphism without functional reason,
- a rounded card around every idea,
- feature-grid after feature-grid,
- excessive badges/pills,
- borders around every grouping,
- fake dashboards,
- invented analytics,
- abstract UI placeholders in final marketing,
- random icon chips for ordinary text,
- identical section layouts repeated down the page,
- parallax just because scrolling exists,
- floating animations that communicate nothing,
- “unlock the power of AI” language,
- copied shadcn/Magic UI/21st.dev examples left visibly unadapted.

## Card test

Before adding a card, ask:

> Is this content an independent object, module, selection or interactive surface?

If no, try whitespace, alignment, typography, divider or surface change first.

## Badge test

A badge should communicate status, category or orientation that is genuinely useful.

Do not place ordinary section labels in pills simply because the component exists.

## Icon test

An icon earns its place if it improves recognition, state, action or scanability.

If removing it changes nothing, remove it.

## Section test

A new section must advance the story/decision.

Two adjacent sections should merge when they express the same beat and differ only in styling.

## Motion test

If the motion disappeared, would meaning disappear?

- If yes: design a reduced-motion equivalent.
- If no: the motion is optional decoration and must justify its cost.

## Mandatory subtraction pass

Before completion, record answers to:

1. Which border did we remove or deliberately keep?
2. Which card/container did we remove or deliberately keep?
3. Could two sections merge?
4. Which icons/badges are actually necessary?
5. What copy was shortened?
6. Is hierarchy coming from type/layout before boxes?
7. Did we add a new visual pattern? Why couldn't an existing one work?
8. Is the primary action obvious within ~2 seconds?
9. Do adjacent sections use the same composition without a reason?
10. Does the whole page feel like one design rather than independently generated sections?

“No changes” is acceptable only with a reason.

## AI-slop smell test

A page is suspect if it could be rebranded to another AI startup by changing only the logo and accent color.

Podlink-specific visual/content evidence should make that difficult:

- episode art,
- real media,
- real transcripts,
- podcast metrics,
- OP3 provenance,
- show reports,
- channel relationships,
- creator presence,
- real client work.

## Premium does not mean more

Premium Podlink should usually mean:

- better hierarchy,
- better product truth,
- better media,
- more deliberate whitespace,
- fewer competing treatments,
- clearer interaction,
- stronger proof,
- more consistent details.

Not more decoration.
